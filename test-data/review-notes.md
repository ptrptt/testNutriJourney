# ข้อสังเกตก่อนทดสอบครบชีต

ต้องยืนยันผลที่คาดหวังของ 3 เคสต่อไปนี้ก่อนตัดสิน Pass/Fail ตามชีต:

| Case ID | ข้อขัดแย้งในชีต | แนวทางทดสอบที่เสนอ |
| --- | --- | --- |
| TC-EHP-005 W1-6 | ขั้นตอนบันทึกน้ำหนัก 58 แล้ว Refresh แต่ Expected บอกว่าไม่บันทึกและแจ้งข้อมูลไม่ครบ | ตรวจว่าน้ำหนัก 58 ยังคงอยู่หลัง Refresh |
| TC-IFG-001W1-8 | เลือก 16:8 แต่ Expected เป็น 18:6 | ตรวจว่าบันทึก 16:8 |
| TC-IFG-002W1-8 | Test Data เปลี่ยนเป็น 20:4, Steps เปลี่ยนเป็น 18:6, Expected บอกให้เลือกรูปแบบ | แยกทดสอบเปลี่ยนจาก 16:8 เป็น 18:6 และ 20:4 |

ข้อเสนอนี้ยังไม่ได้แก้ชีตต้นฉบับ และยังไม่ใช่ผลการทดสอบ

ข้อมูลที่ต้องใช้เพิ่มเติมสำหรับบางเคส:

- สมัครสมาชิก: บัญชี LINE ที่ยังไม่เคยสมัคร
- ข้อมูลว่าง: บัญชีที่ยังไม่มีข้อมูลสุขภาพ/น้ำหนัก/รูป ก่อนทำเคสบันทึกข้อมูล
- กราฟและรูปย้อนหลัง: ข้อมูลหลายเดือนพร้อมค่าที่ทราบแน่นอน
- Character Level 0–9: เกณฑ์ XP และข้อมูลทดสอบแต่ละระดับ
- LINE Notification: การตรวจรับข้อความจริงและรอบการแจ้งเตือนที่กำหนด
- Daily Mission reset: รอบใหม่จริงหรือระบบทดสอบที่ควบคุมเวลาฝั่งเซิร์ฟเวอร์ได้

การเปลี่ยนเวลาของเบราว์เซอร์เพียงอย่างเดียวไม่ยืนยันการส่งแจ้งเตือนหรือ reset ฝั่งเซิร์ฟเวอร์
